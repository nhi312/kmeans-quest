Topic 1 of 8

What is the problem with data?

The Iris dataset has 150 flowers. Each one has four measurements: sepal length, sepal width, petal length and petal width. Normally we also know the species (setosa, versicolor, virginica).

Now imagine the species column is missing. We still have all the numbers, but no labels. Can we find the groups using only the numbers?

Patterns

A pattern is a repeated or recognizable characteristic in data. In the petal plot, flowers of the same species sit close together, so you can see the groups with your eyes.

Why not simple rules?

The slides try hand-made thresholds, like "petal length under 5 cm" or "petal width under 1.8 cm". That breaks down because:

  • some points land on the wrong side of the line,
  • groups can overlap,
  • a pattern can depend on several variables at once,
  • real data is messier than a single cut-off.

So instead of drawing the boundaries ourselves, we let the data find its own groups. That is clustering.

Exam tip. Be ready to explain in one or two sentences why fixed thresholds fail and why clustering helps.
Topic 2 of 8

What is clustering?

Clustering groups similar data points together without using labels. The computer only looks at the numbers (height, weight, petal size…) and measures how close each point is to the others. Points that are close end up in the same cluster.

In short: clustering = finding natural groups in data, automatically.

Key words

  • Label – the "answer" column (like species). Clustering doesn't use it.
  • Unsupervised learning – learning from data with no labels. Clustering is the classic example.
  • Cluster – a group of points that are close to each other.
  • Centroid – the centre of a cluster: the average of its points.
  • K – how many clusters you ask K-means to find.
Exam tip. A common short question: what's the difference between clustering and classification? Clustering has no labels; classification learns from labelled examples.
Topic 3 of 8

Euclidean distance

"Close" needs a number. The slides use Euclidean distance, which is the straight-line distance between two points. It comes straight from the Pythagorean theorem: the horizontal gap and the vertical gap are the two short sides of a right triangle, and the distance is the long side.

2D: d = √((x₂ − x₁)² + (y₂ − y₁)²)
3D: d = √((x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)²)

Higher dimensions work the same way: one more squared difference per extra feature. That's the only change the homework needs for distance.

Worked example: A(2, 10) to D(5, 8)

√((5 − 2)² + (8 − 10)²) = √(9 + 4) = √13 ≈ 3.61

Centre of two points

The centre is the average of each coordinate: CenterAB = ((x₁ + x₂)/2, (y₁ + y₂)/2). For more points, add them all and divide by how many there are. That's exactly how a centroid is computed.

Topic 4 of 8

The K-means algorithm

K-means splits the data into K clusters. Each cluster is represented by its centroid. The algorithm repeats two steps until nothing changes.

1 · Choose KDecide how many clusters, and pick K starting centroids.
2 · AssignEach point joins the cluster of its nearest centroid.
3 · UpdateMove each centroid to the mean of its points.
4 · RepeatGo back to step 2. Stop when no point changes cluster.

Stopping when nothing changes is called convergence. You can't know in advance how many rounds that takes, which is why the homework asks for a while loop: while something changed, keep going.

Good to know

  • Different starting centroids can give different final clusters.
  • You have to pick K yourself. The elbow method (below) helps.
  • If a cluster ends up with no points, you can't average it. Keep its old centroid.

Topic 5 of 8

How do we choose the best K?

The slides run K-means on Iris with no labels for K = 1, 2, 3, 4, 5:

  • K = 1: everything is one big group. Not useful.
  • K = 2: the clearly separate group splits off, but two species stay merged.
  • K = 3: matches the real structure well.
  • K = 4, 5: real groups get chopped into pieces that don't mean anything.

So which K is "most reasonable"? Eyeballing works in 2D, but not in 4D or with lots of data. We need a number to compare. That number is WCSS.

Exam tip. Remember the trap: more clusters always fit the data more tightly, so you can't pick K by "tightest fit wins".
Topic 6 of 8

WCSS: how tight are the clusters?

WCSS stands for Within-Cluster Sum of Squares. It measures how close points are to their own centroid.

  1. For each point, find the squared distance to its cluster's centroid (no square root!).
  2. Add all of them up.
WCSS = Σ (x − cₓ)² + (y − c_y)² over every point, using its own centroid

Smaller WCSS → points are closer to their centroids → more compact clusters.

Worked example (K = 3, final slide clusters)

WCSSA = (2 − 3.67)² + (10 − 9)² + (5 − 3.67)² + (8 − 9)² + (4 − 3.67)² + (9 − 9)² ≈ 6.67
WCSSD ≈ 2.67 · WCSSG = 5.00
WCSS = 6.67 + 2.67 + 5.00 = 14.34 (14.33 if you keep exact fractions)
Exam tip. The two classic mistakes: taking the square root (that's distance, not squared distance) and using the wrong cluster's centroid for a point.
Topic 7 of 8

The elbow method

The elbow method picks a reasonable K:

  1. Run K-means for K = 1, 2, 3, …
  2. Compute WCSS for each K.
  3. Plot K (x-axis) against WCSS (y-axis).
  4. Find the point where the curve bends and flattens: the elbow. That K is your choice.

Why it works: as K grows, WCSS always goes down (with K = number of points, WCSS is 0). At first each extra cluster gives a big drop because it separates real groups. After the right K, extra clusters only split a real group, so the drop becomes small. The turning point looks like an elbow.

Example curve from the Iris-style data in level 4: big drops up to K = 3, then almost flat. Elbow at K = 3.

Exam tip. If asked "why not choose the K with the lowest WCSS?": because that would always be the largest K. We want the point of diminishing returns.

for vs while

A for loop runs a fixed number of times, like for i in range(10), whether the clusters settled after 2 rounds or need 15. A while loop keeps going while a condition is true. Here the condition is "the centroids moved last round". Set changed = True before the loop so it runs at least once, and recompute it at the end of every iteration.

Pseudo-code

K = 3
centroids = 3 starting points
changed = True
while changed:
    assign every point to its nearest centroid (3D distance)
    new_centroids = mean x, y, z of each cluster
    changed = (new_centroids != centroids)
    centroids = new_centroids
plot clusters + centroids in 3D

When does K-means stop?
When an iteration changes no point's cluster, so the centroids no longer move (convergence).

We don't know in advance how many iterations are needed. A while loop keeps going until nothing changes.
